🎬 Movie Analysis Dashboard | Power BI Project

📌 Project Overview

This project focuses on analyzing movie data using Microsoft Power BI. It provides insights into movie releases, genres, IMDb ratings, and runtime through interactive visualizations and reports.

🎯 Objectives

- Analyze yearly movie release trends.

- Identify the most common movie genres.

- Evaluate audience preferences using IMDb ratings.

- Compare ratings across different genres.

- Analyze movie runtime and rating patterns.

- Generate meaningful insights from movie data.

🛠️ Tools Used

- Microsoft Power BI
- Power Query
- DAX
- Microsoft Excel

📊 Key Performance Indicators (KPIs)

- Total Movies
- Average IMDb Rating
- Average Movie Runtime
- Highest Movie Releases by Year

📈 Key Insights

- Identify the year with the highest number of movie releases.
- Understand the distribution of movies across genres.
- Analyze average IMDb ratings.
- Compare movie ratings and runtime patterns.
